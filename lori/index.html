О проекте

Lori — приложение, которое позволяет отслеживать калории, тем самым следить за питанием. Продукт не ограничивается только трекингом калорий, но и позволяет генерировать готовые рецепты с помощью искусственного интеллекта.

Проблемы

Большинство приложений для отслеживания питания сталкиваются с одинаковой проблемой — низкое удержание пользователей. Люди начинают считать калории, но быстро бросают это. Основные причины:

  • Неудобно добавлять продукты;
  • Быстро пропадает мотивация;
  • Нужно вручную вводить данные;
  • Сложно планировать рацион.

В результате приложение превращается в рутинный инструмент, которым по итогу перестают пользоваться.

Цели проекта

Создать приложение, которое будет удерживать пользователей не только за счет удобного функционала трекинга, но и вовлекающих механик. Для этого нужно создать продукт, который одновременно:

  • Упрощает трекинг питания;
  • Помогает быстро составлять рацион;
  • Мотивирует пользователя продолжать следить за питанием.

Мои задачи

Я составил userflow, CJM и JTBD мобильного приложения. После согласования структуры, я перешел к дизайну MVP версии мобильного приложения.

Ключевые решения

Главный экран

Главный экран показывает ключевую информацию о питании пользователя.

Основные элементы:

  • Количество оставшихся калорий;
  • Баланс БЖУ;
  • Информация о приемах пищи;
  • Быстрый доступ к добавлению продуктов.

Добавление еды выделено контрастной кнопкой, так как это основной сценарий приложения.

Пищевой баланс

Далее идет блок с информацией о пищевом балансе. С помощью табов можно смотреть разную информацию. Вкладка Structure показывает точную граммовку БЖУ, а вкладка Meal четкое деление по приемам пищи.

Далее идет блок с информацией по завтраку, обеду и ужину. График показывает каждый продукт в его процентном соотношении.

Генерация блюд

Одной из ключевых функций приложения стала генерация рецептов.

Пользователь может:

  • Добавить продукты, которые есть дома;
  • Получить рецепт блюда из этих ингредиентов.

Это упрощает планирование питания и повышает ценность продукта.

Быстрое добавление еды

Чтобы ускорить трекинг питания, я добавил несколько способов добавления продуктов:

  • Поиск продуктов;
  • Добавление рецептов;
  • Сканирование штрих-кода;
  • Использование камеры для распознавания продуктов.

Результаты

  • Удержание (7 дней): 68% пользователей;
  • Каждый 3-ий пользователь воспользовался AI-помощником;
  • Благодаря напоминаниям через маскота увеличил retention;
  • Благодаря удобным графикам и дашбордам повысил вовлеченность.
